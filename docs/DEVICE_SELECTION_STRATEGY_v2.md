# 设备匹配和选择策略指南 v2.0

## 🎯 问题背景

当您在XML中输入设备关键字（如"头戴式耳机"）时，可能会找到多个设备实例。系统现在支持**智能自动选择**以及**采样率过滤**。

---

## 🚀 四层级选择策略

### **1. 精确配置（最推荐）**

```python
DEVICE_CONFIG = {
    "headphones": 14,
    "microphone": 1,
}
```
```xml
<step device="headphones" ... />
```
✅ **最快** | ✅ **100%准确** | ✅ **维护简单**

---

### **2. 采样率过滤（推荐）⭐ 新功能**

```xml
<step device="AH 22 M 44100" ... />
```

**支持的采样率：** 8000, 11025, 16000, 22050, 32000, 44100, 48000, 96000, 192000

**工作流程：**
```
输入: "AH 22 M 44100"
  ↓
系统识别采样率: 44100
  ↓
搜索 name包含"AH 22 M" 且 采样率=44100 的设备
  ↓
找到6个匹配
  ↓
按照多层级标准排序 (通道数 > 设备名称)
  ↓
✓ 选择 ID 4 (2通道, 44100Hz)
```

**实际输出：**
```
[DeviceManager] 找到 6 个匹配 'AH 22 M 44100' 的设备:
  ✓ 已选 [ID  4] 采样率 44100 Hz, 2通道 - 头戴式耳机 (2- ALE AH 22 M)
     [ID 11] 采样率 44100 Hz, 2通道 - 头戴式耳机 (2- ALE AH 22 M)
     [ID 25] 采样率 44100 Hz, 2通道 - 头戴式耳机 (ALE AH 22 M)
     [ID  1] 采样率 44100 Hz, 1通道 - 耳机式麦克风 (2- ALE AH 22 M)
     [ID  8] 采样率 44100 Hz, 1通道 - 耳机式麦克风 (2- ALE AH 22 M)
     [ID 26] 采样率 44100 Hz, 1通道 - 耳机式麦克风 (ALE AH 22 M)
```

✅ **精确指定** | ✅ **自动适应系统变化** | ✅ **灵活**

---

### **3. 关键字匹配（自动选最优）**

```xml
<step device="头戴式耳机" ... />
```

**选择标准（优先级从高到低）：**
1. 采样率越高越好 (48000 > 44100 > 32000)
2. 通道数越多越好 (2 > 1)
3. 设备ID越小越好

**实际输出：**
```
[DeviceManager] 找到 8 个匹配 '头戴式耳机' 的设备:
  ✓ 已选 [ID 14] 采样率 48000 Hz, 2通道 - 头戴式耳机 (2- ALE AH 22 M)
     [ID  4] 采样率 44100 Hz, 2通道 - 头戴式耳机 (2- ALE AH 22 M)
     [ID 11] 采样率 44100 Hz, 2通道 - 头戴式耳机 (2- ALE AH 22 M)
     [ID 25] 采样率 44100 Hz, 2通道 - 头戴式耳机 (ALE AH 22 M)
     [ID 18] 采样率 48000 Hz, 1通道 - 耳机式麦克风 (2- ALE AH 22 M)
     [ID  1] 采样率 44100 Hz, 1通道 - 耳机式麦克风 (2- ALE AH 22 M)
     [ID  8] 采样率 44100 Hz, 1通道 - 耳机式麦克风 (2- ALE AH 22 M)
     [ID 26] 采样率 44100 Hz, 1通道 - 耳机式麦克风 (ALE AH 22 M)
```

✅ **最灵活** | ⚠️ **查询稍慢** | ✅ **自动选最优**

---

### **4. 设备ID（直接指定）**

```xml
<step device="4" ... />
```

✅ **最快** | ✅ **100%准确** | ⚠️ 需知道ID

## 💡 应用场景

### **场景1：需要固定采样率的测试**

```xml
<!-- 必须使用44100Hz的设备 -->
<step type="audio" action="play_async" 
      content="sine_44100.wav" device="AH 22 M 44100" />

<!-- 必须使用48000Hz的设备 -->
<step type="audio" action="play_async" 
      content="sine_48000.wav" device="AH 22 M 48000" />
```

### **场景2：生产环境（稳定性优先）**

```python
DEVICE_CONFIG = {
    "playback": 4,      # 明确指定设备
    "recording": 1,
}
```
```xml
<step device="playback" ... />
<step device="recording" ... />
```

### **场景3：多系统环境（自适应）**

```xml
<!-- 自动选择最优的设备，适应不同系统 -->
<step type="audio" action="play_async" 
      content="file.wav" device="耳机" />
```
